# 🌿 Greenden

Greenden is a modern, responsive website for a plant and gardening brand, built using **HTML** and **Tailwind CSS**.

The project focuses on creating a clean, visually appealing interface with responsive layouts that work smoothly across mobile, tablet, and desktop screen sizes.

## ✨ Features

* 📱 Fully responsive design
* 🌿 Modern plant and gardening themed UI
* 🎨 Styled with Tailwind CSS
* 🖥️ Responsive layouts for different screen sizes
* 🧭 Navigation and multiple pages
* 📦 Product showcase section
* 📩 Contact page
* ⚡ Lightweight frontend implementation

## 🛠️ Technologies Used

* **HTML5**
* **Tailwind CSS**
* **JavaScript** *(if applicable)*

## 📄 Pages

* **Home** – Introduction and featured content
* **Products** – Displays available plants/products
* **Contact** – Contact and enquiry section

## 📱 Responsive Design

Greenden is designed to provide a consistent experience across:

* 📱 Mobile devices
* 📲 Tablets
* 💻 Laptops
* 🖥️ Desktop screens

Tailwind CSS responsive utility classes were used to adapt the layout and components to different screen sizes.

## 🎯 Project Purpose

This project was created to practice and demonstrate frontend development skills, particularly:

* Building responsive web layouts
* Working with Tailwind CSS
* Creating reusable UI structures
* Designing multi-page websites
* Developing mobile-friendly interfaces

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ryukbyte/Greenden-tailwind.git
```

Navigate to the project folder:

```bash
cd Greenden-tailwind
```

Open `index.html` in your browser to view the website.
